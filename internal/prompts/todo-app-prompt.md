A simple web-based todo app with full CRUD functionality.

### Tech Stack

- React with TypeScript + Vite
- Tailwind CSS for styling
- shadcn/ui for UI components
- localStorage for persistence

### Features

- Add, edit, delete, and mark todos as complete
- Inline editing (double-click to edit, Enter to save, Escape to cancel)
- Filter by status: All, Active, Completed
- Show count of remaining active todos
- Clean, minimal, responsive design
